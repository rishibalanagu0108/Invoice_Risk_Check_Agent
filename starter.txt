# 1. PROJECT OBJECTIVE

Build a small, testable AI agent that evaluates vendor invoices/payment requests under uncertainty.

The agent observes available information about:

* invoice
* vendor
* amount
* bank/payment details
* historical invoices
* historical payment information
* vendor identity information
* email/domain information where available
* other relevant evidence

The true state is not directly observable when the decision is made.

Initial hidden states:

H1 = Legitimate
H2 = Error / anomaly
H3 = Fraud

The agent must select one of these actions:

* APPROVE
* VERIFY
* HOLD
* ESCALATE

The system must explicitly model:

1. Input
2. Evidence
3. Hidden states
4. Beliefs/probabilities
5. Actions
6. Costs
7. Policy
8. Feedback
9. Belief update after new evidence

The system must make an ACTION, not merely produce a chatbot explanation.
